## 3. 데모 대본 v2 (2~3분. 공식 길이 제한 확인) — "보안 기관을 위한 꽂으면 되는 대형 AI"
1. (0:00) 문제 제기: "군과 기업은 내부 정보 유출 때문에 Claude나 ChatGPT를 못 씁니다. 로컬로 돌리자니 노트북은 7B만 돌려도 뜨겁고, 30B 이상은 메모리가 모자랍니다."
2. (0:20) 준비 구역 화면(인터넷 O): `fleet-plan`에서 Muse Spark가 대상 노트북 3종의 사양으로 드라이브 구성 브리프를 작성합니다. `qualify`에서 양자화 후보를 채점해 "합격한 가장 작은 모델"을 고릅니다. 이어서 `seal`로 서명합니다.
3. (0:50) USB 2개를 맥북 에어(또는 16GB 노트북)에 꽂고 Wi-Fi를 끕니다. UI 배지: `AIR-GAP: no network`, `integrity: verified`, `thermal: … → balanced`
4. (1:05) 판정표: Qwen3-30B-A3B나 Llama 4 Scout가 "expert streaming from drive"로 표시되고, 메모리 내역과 속도 상한이 나옵니다.
5. (1:20) 같은 모델을 **기본 llama.cpp**와 **PocketLLM 엔진**으로 나란히 생성합니다. tok/s와 드라이브 읽기량이 실시간으로 보입니다(실험실 수치: 드라이브 1개에서 약 6배).
6. (1:50) 드라이브를 1개 → 2개로 바꿔 stripe한 모델의 속도 변화를 보여 줍니다.
7. (2:10) 드라이브 파일 1바이트를 변조하면 `integrity: FAILED`가 뜨고 로드가 거부됩니다.
8. (2:25) 로드맵: 연산 노드(`pocketllm node`)를 전용 케이블로 추가하는 클러스터 모드, 그리고 장치 메모리를 가진 USB 컴퓨트 모듈

화면에 항상 표시할 문구: "Inference runs on this computer's CPU/GPU. The drive stores software and models."

## 5. 심사 기준 대응 (비중은 미검증)
- **Impact**: "다운로드 전에 정직한 판정"으로 비전문가의 실패 비용(시간, 디스크, 실망)을 없앱니다. 오프라인과 개인정보 보호도 해당합니다.
- **Meta 기술 활용**: Muse Spark는 실행 제약 해석에, Meta 오픈 웨이트는 실제 로컬 추론에 씁니다. 장식이 아니라 핵심 흐름에 들어 있습니다.
- **기술 깊이**: GGUF 텐서 단위 메모리 회계, MoE 전문가 단위 배치(`-ncmoe`), 대역폭 기반 속도 상한, 잡음을 고려한 실측 튜닝, 통합 메모리 회계, 버전 고정 런타임
- **데모**: USB 연결 → 판정 → 채팅 → 튜닝 → 오프라인 전환의 연속 흐름
